# tablecrm-order

Веб-приложение для управления заказами на **Next.js + TypeScript** с интеграцией TableCRM.

## Стек
- **Next.js** (App Router) · **React** · **TypeScript**
- **Tailwind CSS** + shadcn/ui
- Деплой на **Vercel**

## Запуск
```bash
npm install
npm run dev   # http://localhost:3000
```

## Структура
- `src/` — страницы, компоненты, логика приложения
- `public/` — статические файлы
- `vercel.json` — конфигурация деплоя
