# tablecrm-order

Веб-приложение для оформления заказов поверх TableCRM. Менеджер вводит токен, ищет контрагента по телефону, набирает товары из номенклатуры, выбирает склад, кассу, организацию и тип цены, а на выходе в CRM создаётся продажа.

Приложение работает напрямую с публичным API TableCRM, своего бэкенда у него нет: токен лежит в localStorage браузера и подставляется в каждый запрос. Ответы у разных ручек приходят в разной форме, где-то массивом, где-то объектом с ключом `result`, `items` или `data`, поэтому в клиенте есть общий распаковщик, который приводит всё к списку и избавляет остальной код от проверок.

## Стек

Next.js на App Router, React, TypeScript, Tailwind CSS с компонентами shadcn/ui, иконки lucide, уведомления sonner. Деплой на Vercel.

## Запуск

```bash
npm install
npm run dev   # http://localhost:3000
```

Токен TableCRM вводится на стартовой странице и сохраняется в браузере.

## Структура

```
src/app/         страницы: вход и экран заказа
src/components/  UI-компоненты
src/lib/api.ts   обёртка над API TableCRM
```
